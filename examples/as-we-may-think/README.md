# As We May Think · reading example

A buildless static reading page using Daphnis Glass. It imports `../../glass.js` and `../../glass.css` directly. Serve the repository as static files, or run `npm run demo` from the repository root and open `/examples/as-we-may-think/`.

The example has a single text column, native section links, a sticky glass reading bar, working text-size controls, and material selection. It has no annotation system, iframe, application server, user account, analytics, external fonts or runtime dependencies. The essay remains readable if JavaScript or the glass enhancement is unavailable. Reading controls do not depend on the glass import succeeding.
